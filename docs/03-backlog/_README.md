# docs/03-backlog/

Dos artefactos:

- `epicas.md` — descomposición del PRD en épicas con trazabilidad a objetivos. Generar con `/trycore:epicas`.
- `backlog.md` — tabla ordenada de historias. Generar con `/trycore:backlog` (consume las historias de `docs/04-historias/`).

**Regla**: el orden de filas en `backlog.md` ES la priorización. Cada épica se traza a ≥ 1 objetivo del PRD.
