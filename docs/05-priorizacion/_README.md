# docs/05-priorizacion/

Sesiones de priorización. Un archivo por sesión: `<framework>-YYYY-MM-DD.md` (ej. `moscow-2026-05-20.md`).

Generar con `/trycore:priorizar` — elige framework (MoSCoW / RICE / Valor-Esfuerzo / Eisenhower).

**Regla**: el framework se aplica completo, no parcial. Si todo termina como "Must" en MoSCoW, reabrir la discusión. Ver `METODOLOGIA.md` §7.
