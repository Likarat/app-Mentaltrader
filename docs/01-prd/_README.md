# docs/01-prd/

Aquí vive el PRD del proyecto. Crearlo con `/trycore:prd` (o como parte de `/trycore:flujo`).

**Convención**: un archivo por PRD vigente (típicamente uno solo). Si el producto tiene módulos independientes, puede haber varios PRDs (`prd-modulo-A.md`, `prd-modulo-B.md`).

**Regla**: el PRD debe contener los 12 componentes obligatorios. Ver `~/trycore-spec-product-flow/METODOLOGIA.md` §1.
